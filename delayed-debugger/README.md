# Delayed Debugger

Runs a `debugger` statement on the current page immediately or after a selected delay of 2, 4, 6, or 8 seconds.

## Installation

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `delayed-debugger` folder.
5. Pin the extension to the toolbar if needed.

Click the extension icon, choose a delay, and open DevTools before the timer expires so Chrome pauses at the `debugger` statement. The extension cannot run on Chrome internal pages or the Chrome Web Store.
